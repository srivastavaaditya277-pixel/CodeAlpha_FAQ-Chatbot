# 🤖 FAQ Chatbot

An AI-based FAQ Chatbot developed as part of my CodeAlpha Internship.

## 📌 Project Description

This project is a simple FAQ chatbot that allows users to ask questions and receive the most relevant answers from a predefined FAQ dataset.

The chatbot uses text preprocessing and keyword-based matching to identify the best matching FAQ.

## ✨ Features

- 💬 Interactive chatbot interface
- 🧠 FAQ-based question matching
- 📚 30+ predefined FAQs
- ⌨️ Enter key support
- 🤖 Typing indicator
- 📋 Copy Answer button
- 🌙 Dark mode
- 💾 Dark mode preference saved using LocalStorage
- 🗑️ Clear chat option
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- NLP-style text preprocessing
- LocalStorage
